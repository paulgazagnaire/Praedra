# Praedra

Praedra is our strategy game, in Godot 4 with a C# rules core. It is built on a classic base game (called **Classic** everywhere in the code); that base's names and mechanics are placeholders we keep replacing with our own universe. Private: it holds data converted from Paul's own copy of the Classic game, so it must never be made public.

The design specs live in the project's shared folder (`praedra/specs/`), not here. The development plan is `specs/engine/04-development-plan.md` and the rule book is `specs/engine/rules/`.
