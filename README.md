# Praedra

Praedra is our game: a full rebuild of Star Wars: Rebellion (1998) in Godot 4 with a C# rules core, moving to its own universe. Code names (`Rebellion.sln`, `Rebellion.Core`, `RebellionViewer`) keep the old word for now; renaming them is a separate, later change. Private: it will hold data converted from Paul's own copy of the original game, so it must never be made public.

The design specs live in the project's shared folder (`rebellion/specs/`), not here. The development plan is `specs/engine/04-development-plan.md` and the rule book is `specs/engine/rules/`.
