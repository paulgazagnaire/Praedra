# Rebellion

A full rebuild of Star Wars: Rebellion (1998) in Godot 4 with a C# rules core. Private: it will hold data converted from Paul's own copy of the original game, so it must never be made public.

The design specs live in the project's shared folder (`rebellion/specs/`), not here. The development plan is `specs/engine/04-development-plan.md` and the rule book is `specs/engine/rules/`.
