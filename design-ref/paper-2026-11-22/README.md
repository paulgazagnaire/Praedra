- strength_answers.html: artboard "Fleet strength - the 3 answers - 2026-11-22". Pieces: strength_answers/00_notes.html, 01_row.html.
- img/: the pictures. The HTML points at paper-asset:///Users/paulgazagnaire/Repos/paper-exports/2026-11-22-fleet/img/
- preview/: how each artboard should look (Chromium with the game's fonts), to compare with Paper.

Artboard: background #111214, vertical auto layout, padding 48, gap 48, width hugs its content.
